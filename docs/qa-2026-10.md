## Accessibility (axe-core 4.10, WCAG 2.2 AA rules)

Pages checked: `/`, `/book` (results and empty), `/traenere`, `/klub/[slug]`, `/opret-klub`, `/login`, `/signup`, `/spillere`, `/admin`, `/admin/bookinger`, `/profil`. Fixed during this work: low-contrast secondary text (slate/60 and slate-light), discovery results not being a real list, unnamed map markers, a focusable non-interactive origin marker, dimmed past rows in the schedule, and an unlabelled file input. Remaining: none at moderate severity or above on these pages.

## Journeys exercised with Playwright (phone viewport)

1. Guest → `/klub/brookline-racquet-club` → "Sign in" → signs in → returned to the same club and day → taps an hour → court tile → `/checkout/<id>` → pays (mock) → `/profil?betalt=<id>` with the confirmation panel → downloads `/bookings/<id>/calendar` (valid `text/calendar`, correct UTC instants, venue address, summary).
2. `/book?q=Denver` → no clubs → notify-me form → row written to `MarketInterest`, success message shown.
3. `/opret-klub?plan=CUSTOM` → Lights and door access → facility (state sets the time zone) → courts → account → `/club-start` checklist with the Pay step.
4. Club rule rejection (member over the active-booking cap) shows the translated reason on the club page.
